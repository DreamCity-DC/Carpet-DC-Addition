# Carpet DC Addition

Carpet DC Addition 是为 DreamCity 服务器开发的 [Fabric Carpet](https://github.com/gnembon/fabric-carpet) 服务端附属模组

所有可用的carpet规则详见：[规则文档](docs/rules.md)

## 版本支持状态

| Minecraft版本 | 支持状态  |
| ------------- | --------- |
| 26.3          | ✅ 更新中 |

## 从源码构建

在 Java 25 环境运行：

```sh
./gradlew build
```

Windows 使用：

```bat
gradlew.bat build
```

构建产物位于 `build/libs/`
